Every `hk:` icon, and the SF Symbol it is drawn from — 232 symbols in all, listed one per line in `tools/sf_symbols/symbols.txt`. You don’t need this table to build the glyph file; it is for finding a symbol in the SF Symbols app, checking what an icon should look like, or [exporting the symbols another way](Making-Your-Files.md#no-python-on-the-mac).

A symbol name that your version of SF Symbols doesn’t have (Apple renames one now and then) stops the build with its name. Search for the icon in the SF Symbols app to find the new name, and [open an issue](https://github.com/jazzphone/hk-frontend/issues) so the list can be updated.
